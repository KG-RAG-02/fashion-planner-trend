# 0005 표준 어휘는 K-Fashion 속성 목록

- **상태:** 채택 (2026-11)

## 배경
기사와 두 상품 데이터셋은 색, 카테고리, 소재, 패턴, 디테일을 서로 다른 말로 쓴다. 맞추려면 공통 값 집합이
하나 있어야 한다.

## 결정
K-Fashion 이미지 AI 데이터 구축 가이드라인(AI Hub, Ver 1.04)의 속성 값 목록을 표준으로 쓴다. 색 21, 상분류 4 +
하분류 21, 소재 26, 패턴 19, 디테일 62(디테일 40, 넥라인 12, 칼라 10)와 핏, 셰이프, 기장 목록이다. 상품
데이터셋은 표준이 *아니다*. 그 표현은 별칭 사전을 거쳐 표준 값으로 바뀐다([vocabulary.md](../vocabulary.md)).

## 결과
- 속성마다 코드의 열거형이 하나 있고, 어휘 노드는 한 번 만들어 Item과 Product가 함께 쓴다.
- 가이드라인과 모든 출처가 한국어라 값도 한국어 문자열이다.
- 어휘를 바꾸면 코드가 바뀌고 그래프를 다시 적재해야 한다.

## 검토한 대안
- 상품 데이터셋 하나의 라벨을 표준으로 삼기: 그 데이터의 라벨 잡음과 빈칸이 그대로 스키마가 된다.
