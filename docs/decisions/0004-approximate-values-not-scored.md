# 0004 근사 어휘 매핑은 저장하되 점수에 쓰지 않는다

- **상태:** 채택 (2026-11)

## 배경
원문 표현이 표준 어휘에 정확히 맞지 않을 때가 있다(예: "슬림"은 "타이트"에 가장 가깝다). 모든 말을 억지로 값에
맞추면 불확실성이 가려진다.

## 결정
별칭 사전이 원문 값을 근사로만 매핑하면, 값을 `approx = true`로 저장한다(관계에는 속성으로, 스칼라 필드는 노드의
`approx[]` 목록으로). 근사 값은 상품 후보를 만들지 않고 점수에도 들어가지 않으며, 미확인으로 보고한다.

## 결과
- 점수는 정확한 표준 값에만 기대므로 보수적이고 설명할 수 있다.
- 근사 표현으로만 묘사된 옷은 재현율이 떨어진다.
- 원문 표현은 항상 남기므로(`raw` / `*_raw`) 나중에 매핑을 고칠 수 있다.

## 검토한 대안
- 근사 값을 낮은 가중치로 반영: 맞출 데이터 없이 조정할 손잡이만 하나 늘어난다.
